Privacy policy — Jonna Health Sync

Effective 8 November 2026

Who uses this app

Jonna Health Sync is a personal tool with a single user, who is also its developer. No one else can sign in to it.

What data it reads

With the user's consent, it reads her own data from the Google Health API using read-only scopes: activity and fitness, health metrics and measurements, sleep, and profile. It never writes to Google Health.

How the data is used and stored

The data is used only to build the user's own daily training and recovery summary. It is stored on the user's own computer and in her private code repository. It is not sold, not shared with third parties, not used for advertising, and not used to train any model.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data can be deleted by the user at any time.
